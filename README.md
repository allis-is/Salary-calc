# SalaryCalc — это веб-приложение для автоматического расчёта заработной платы по
сдельно-премиальной схеме. Система позволяет учитывать выполненные работы,
рассчитывать премии, налоги и формировать ведомости.
## Структура проекта
Проект состоит из 4 основных страниц:
- Авторизация (регистрация нового пользователя)
- Вход (аутентификация существующего пользователя)
- Главная страница (основной функционал)
- Профиль пользователя (данные и история начислений)
- - -
## Функционал проекта
### Главная страница
На главной странице пользователь может:
- Просмотреть список выполненных работ
-  Рассчитать заработную плату:
  - Сдельная часть (объём × тариф)
- Рассчитать налоги (НДФЛ)
- Получить итоговую сумму к выплате
- - -
### Страница профиля пользователя
На странице профиля отображается:
- ФИО сотрудника
- Должность
- Дата приема
- Участок
- История выполненных работ
- История начислений
- - -
## Особенности проекта
- Расчет зарплаты на основе выполненных работ
- Формирование расчетной ведомости
- Использование расценок из прейскуранта
- Удобный интерфейс для пользователей
